📚 Advanced Student Study Planner Web Application  
Developed by Jayshri Gautam

This project is a modern web application designed to help students plan and manage their daily study tasks effectively.

✨ Key Features
✅ Add study tasks with subject and deadline  
✅ Priority-based task management (Low, Medium, High)  
✅ Subject-wise task filtering  
✅ Task completion tracking  
✅ Study progress tracker with dynamic progress bar  
✅ Pomodoro study timer for focused study sessions  
✅ Data saved using Local Storage  
✅ Clean and responsive user interface  

🛠 Technologies Used
💻 HTML  
🎨 CSS  
⚡ JavaScript  
💾 Local Storage  

🎯 Purpose of the Project
The goal of this project is to improve productivity for students by providing a simple and interactive study planning system.
